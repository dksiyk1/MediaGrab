# MediaGrab 界面方案 · 四套设计规范

四套都基于同一信息架构：**链接输入 → 结果卡（封面/标题/元信息）→ 图集缩略图 → 清晰度选择 → 下载动作**。
只更换视觉语言，便于对比与替换。

- 设计尺寸：1200 × 800（逻辑像素），导出 @2x
- 数据为真实作品：抖音图文《就算变成小僵尸》3 张、2160 × 3024
- 文件：`a-windows.html` `b-macos.html` `c-material.html` `d-editorial.html`
- 渲染：`python tests/shot_design.py`（有头模式，见下方「坑」）

### 链接导入条（一级操作区）

链接导入是这个软件的核心动作，必须是一级元素，**不能塞进 52px 工具栏**。

| 项目 | 值 |
|---|---|
| 容器 | 全宽 976，高 68，`padding 14/18/15`，`.5px` 下描边 |
| 输入框 | `flex:1` → 872 × 38，圆角 9，白底 + `0 1px 2px` 阴影 |
| 文字 | 13.5px / 780px 可用宽（≈ 106 个英文字符） |
| 内嵌粘贴 | 24 高，圆角 6，`rgba(120,120,128,.14)` |
| 解析按钮 | 60 × 38，圆角 9，主色渐变 `#1B87FF → #0071E3`，字重 600 |

**为什么不用原来的 200×28**：可用文字宽仅 163px ≈ 25 字符，而抖音短链 36 字符、B站链接 42 字符，尾部会被截断 —— 用户看不到自己粘的是哪条。

**三态**：空态（灰色提示「粘贴抖音 / B站 / 小红书链接，支持批量」）→ 已填（链路图标 + 链接本体 + 粘贴）→ 解析中（按钮转 loading，输入框 `readonly`）。

**兜底**：超过 106 字符时 `text-overflow: ellipsis` 收尾 + `title` 属性提供完整内容。但正常情况不该走到这里 —— **粘贴后应自动提取 URL，输入框只留链接本体**（抖音复制的完整分享文案有 88 字符，含大量中文前缀，整串展示本身就是错的交互）。

## D · Editorial（自创）

设计主张：**把下载工具做成一份刊物**。

| 项目 | 值 |
|---|---|
| 底色 | `#17160F`（暖墨） |
| 面 | `#1E1D15` / `#242219` |
| 线 | `rgba(240,232,214,.13)` / `.26` |
| 文本 | `#F2EBDC` / `#A49D8B` / `#6B6659` |
| 强调 | `#E0A458`（琥珀），深色字压在上面 |
| 字体 | 标题 Georgia → 宋体（26px 以上宋体不发虚）；界面文字 Segoe UI |
| 圆角 | 2px（刻意接近方角） |
| 特征 | 用线不用面、编号系统（FIG. / PLATES / CONTENTS / ISSUE）、10px 宽字距小标签 |

三条让它成立的规则：
1. **靠分割线组织版面**，几乎不用卡片底色和阴影
2. **字号对比拉到极限**：34px 衬线大标题 vs 10px 大写字距标签
3. **一切编号**，制造目录感和秩序感

## 实现时会踩的坑（都已在文件里规避）

### 坑 1 — `-webkit-line-clamp` 会让 emoji 变方块

Chromium 在 line-clamp 的特殊排版盒里会跳过 emoji 字体回退，`🎶` `📷` 直接渲染成 tofu。

改为 `max-height: 2.8em; overflow: hidden`，视觉一致且不踩雷。

### 坑 2 — `backdrop-filter` 同样会让 emoji 变方块

大面积毛玻璃会让整棵子树走 GPU 合成，字体回退失效。macOS 方案的 vibrancy 因此改成纯半透明色透色（壁纸本身是柔和渐变，观感几乎无差）。

### 坑 3 — 字体栈里 `-apple-system` / `SF Pro` 不能打头

在 Windows 上这两个名字会被解析并"吞掉" emoji 字形。字体栈要 **Segoe UI 家族优先，SF Pro 最后兜底**。

### 坑 4 — 截图必须用有头浏览器

headless 的 Edge/Chromium 不加载系统 emoji 字体，所有 emoji 都会变方块。
`tests/shot_design.py` 用 `headless=False` + `--window-position=-32000,-32000` 把窗口挪出屏幕。

### 坑 5 — `file://` 有缓存

改完 CSS 不刷新会一直出旧图，URL 需要挂 `?v=timestamp`。

## 怎么选

| 你的情况 | 建议 |
|---|---|
| 只想让用户觉得"这就是个正常的 Windows 软件" | **A** |
| 用户偏设计/创作人群，产品要显质感 | **B** |
| 未来要上移动端 / 平板，希望一套设计语言通用 | **C** |
| 想做出辨识度、愿意承担一点学习成本 | **D** |
| 不确定 | **A 打底 + D 的排版细节**（编号、细分割线、字号对比） |
